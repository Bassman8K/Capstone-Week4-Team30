# Team photos

Upload your photo here directly through GitHub's website (Add file → Upload files).

- Name it something simple: your first name, lowercase, no spaces — e.g. `mei.jpg`
- Square photos look best (the card crops to a circle)
- Any common image format works (`.jpg`, `.png`, `.webp`)

After uploading, set `photoUrl: '/team/<your-file-name>'` for your entry in
`frontend/src/features/team/data.ts` — see `docs/ADD-YOURSELF-TO-TEAM-PAGE.md`
for the full walkthrough.
